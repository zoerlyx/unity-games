# 🎮 UNITY GAMES

> A collection of Unity-based interactive games developed for educational and psychological research.

This repository contains two **Unity Windows games** developed as interactive research and educational applications. Each game explores a different interaction model, ranging from FPS-based visual attention to voice-based vocabulary learning.

---

## 🎮 Games

### 🎃 Shoot the Pumpkin

**FPS • Shooting • Unity • Windows**

**Shoot the Pumpkin** is a first-person shooting game where players navigate a 360° environment and shoot randomly spawning pumpkins within a fixed time limit.

Players must maintain their focus and reaction speed while avoiding non-target objects such as black rabbits and bats, which apply score penalties.

#### ✨ Features

- 🎯 Dual difficulty modes — Easy & Hard
- 🔄 360° first-person camera
- 🎃 Randomly spawning targets
- 🏆 Real-time precision scoring
- ⏱️ Time-limited gameplay
- 🐇 Non-target penalty mechanics
- 🧠 Designed for cognitive focus and visual attention research

#### 🎯 Project Goal

Developed as a **client project for psychological research** to measure and evaluate:

- Cognitive focus
- Reaction time
- Visual attention
- Target identification
- Decision-making under time pressure

### 🗣️ VocaPlay

**Educational • Voice Recognition • Unity • Windows**

**VocaPlay** is an educational pronunciation game set in a retro pixel-art world. Players interact with visual image prompts and must correctly pronounce the target vocabulary in their selected language to progress through stages and earn rewards.

#### ✨ Features

- 🎙️ Real-time voice recognition
- 🌐 Multilingual vocabulary learning
- 📷 Live camera integration
- 🔊 Audio feedback
- 🎨 Retro pixel-art environment
- 🏆 Stage progression and rewards
- 🧠 Designed for language and auditory memory research

#### 🌐 Supported Languages

- 🇸🇦 Arabic
- 🇬🇧 English
- 🇮🇩 Sundanese
- 🇮🇩 Javanese

#### 🎯 Project Goal

Created for an **educational psychology study** exploring interactive approaches to:

- Language acquisition
- Speech and pronunciation training
- Auditory memory retention
- Vocabulary learning
- Interactive educational experiences
