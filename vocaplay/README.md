# 🗣️ VOCAPLAY

> **Educational Game • Voice Recognition • Unity • Windows**

**VocaPlay** is an educational pronunciation game set in a retro pixel-art world. Players are presented with visual image prompts and must correctly pronounce the corresponding vocabulary in their selected language to progress through stages and earn rewards.

## 🎮 Game Overview

Players explore a retro-inspired world while completing vocabulary challenges based on visual prompts.

Each stage presents an image representing a target word. Players must pronounce the word correctly using their microphone. The voice recognition system analyzes the player's speech and provides immediate feedback, allowing them to learn through interactive repetition.

## ✨ Features & Vision

### 🎙️ Voice Recognition System

Real-time speech input analysis evaluates the player's pronunciation and determines whether the spoken vocabulary matches the target.

### 🌐 Multilingual Support

Choose from four available languages:

- 🇸🇦 Arabic
- 🇬🇧 English
- 🇮🇩 Sundanese
- 🇮🇩 Javanese

### 📷 Live Camera & Audio Feedback

Integrated camera and microphone interaction provides immediate audio-visual feedback, helping players understand whether their pronunciation is correct or incorrect.

### 🎓 Project Goal

VocaPlay was created for an **educational psychology study**, exploring the use of interactive games to support:

- Language acquisition
- Speech and pronunciation training
- Auditory memory retention
- Vocabulary learning
- Interactive learning experiences

## 🕹️ Gameplay

1. Select a language.
2. Enter the vocabulary challenge.
3. Observe the visual image prompt.
4. Pronounce the corresponding vocabulary using the microphone.
5. Receive instant feedback.
6. Progress through the stages and earn rewards.
