# 🎃 SHOOT THE PUMPKIN

> **FPS • Shooting • Unity • Windows**

**Shoot the Pumpkin** is a first-person shooting game where players navigate a 360° environment and shoot randomly spawning pumpkins within a limited time.

Players must maintain their focus and reaction speed while avoiding non-target objects such as black rabbits and bats, which reduce the player's score when shot.

---

## 🎮 Game Overview

Players enter a dynamic FPS environment where pumpkins randomly appear throughout the map.

The objective is simple: **shoot as many pumpkins as possible before the timer runs out**.

However, players must stay alert. Shooting non-target objects such as black rabbits and bats results in score penalties, making visual attention and decision-making essential for achieving a high score.

---

## ✨ Features & Vision

### 🎯 Dual Difficulty Modes

Choose between **Easy** and **Hard** difficulty modes, each featuring different map layouts and progressively challenging gameplay conditions.

### 🔄 360° FPS Camera

An immersive first-person camera allows players to freely look around the environment and track targets from every direction.

### 🏆 Precision Scoring System

The game features real-time score calculation combined with a fixed time limit and target-based scoring penalties.

- 🎃 Shoot pumpkins to increase your score
- 🐇 Avoid black rabbits
- 🦇 Avoid bats
- ⏱️ Complete as many successful shots as possible before time runs out

### 🧠 Research-Oriented Gameplay

The game was developed as a **client project for psychological research**, designed to measure and evaluate aspects of:

- Cognitive focus
- Reaction time
- Visual attention
- Target identification
- Decision-making under time pressure

## 🎯 Project Goal

The primary goal of **Shoot the Pumpkin** is to provide an interactive FPS environment that can be used to observe player performance in situations requiring rapid visual recognition, focused attention, and quick reaction.

The project demonstrates how a game-based environment can be designed to support controlled psychological research scenarios while maintaining engaging gameplay.
